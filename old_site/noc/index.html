Technology Stack

The modern, high-performance software architecture powering the comprehensive State NOC monitoring ecosystem.

Frontend Interface

  • Core: HTML5, CSS3, JavaScript (ES6+)
  • Visualization: Chart.js Data Analytics
  • Design System: Custom Glassmorphism UI
  • Assets: FontAwesome 6, Google WebFonts

Backend API Core

  • Engine: PHP 8.2 (FastCGI Execution)
  • Server: Microsoft IIS 10.0 Native HTTP
  • Storage: Atomic JSON Document Store
  • Persistence: Windows Task Scheduler

Monitoring Daemons

  • Parallel Ping: PowerShell 5.1 Runspaces
  • Hardware Poller: Python 3.10 (PySNMP)
  • Protocols: SNMP v2c/v3, ICMP, UDP
  • Analytics: PHP Network Outage Heuristics

Machine Learning

  • Vision Engine: EasyOCR Framework
  • Tensor Layer: PyTorch (CPU-Optimized)
  • Extraction: Thermal IP Cam Text Parsing
  • LLM Engine: Ollama (Self-Hosted LLM)
