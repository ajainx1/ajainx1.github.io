NOC Engineer Troubleshooting Matrix & Incident Playbook
1. Codec Status OFFLINE / Unreachable
Check physical power & RJ-45 LED on Panasonic KX-VC1300. Ping SWAN Gateway IP 10.X.X.0. Verify switch port VLAN 100 access and 1000Mbps Full Duplex link status.
2. High Jitter (>15ms) or Video Stutter
Inspect SWAN Router interface Queue drops. Verify Expedited Forwarding (EF/46) QoS profile on SWAN edge node. Ensure MTU is clamped at 1420 to prevent packet slicing over VPN tunnels.
3. One-Way Audio or Black Screen Video
Check firewall UDP ACLs for RTP port range 16000-20000. Verify NAT Traversal / STUN / TURN configuration on State Hub Core Switch. Re-register SIP session via Codec Web UI.
